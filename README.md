# Tusumba - дизайн-система и вайрфреймы

> Статус: черновые материалы для согласования и реализации в Спринте 1.  
> Задачи: \[#18898 — Дизайн-система Material 3](https://ai.nsu.ru/issues/18898), \[#18899 — Вайрфреймы основных экранов](https://ai.nsu.ru/issues/18899).

## Назначение

Tusumba — веб-платформа для поиска мероприятий и секций, записи на занятия и взаимодействия с организаторами. Подготовленные дизайн-материалы задают общий визуальный стиль и расположение основных элементов интерфейса. Их задача — помочь фронтенд-разработчикам реализовывать страницы в едином стиле и согласовать логику экранов до разработки.

**Важно:** HTML-файлы в этой части репозитория — демонстрационные макеты, а не готовая реализация веб-клиента или подключение к API.

## Что подготовлено

### \#18898 — Дизайн-система

* Базовое визуальное направление на основе Material Design 3: цвета по назначению, светлая и тёмная темы, типографика, отступы и скругления.
* Набор базовых UI-элементов: кнопки, поля ввода, фильтры, карточки мероприятий, верхняя панель, нижняя навигация.
* Состояния компонентов: обычное, активное/выбранное, отключённое, ошибка, загрузка — там, где применимо.
* Токены и материалы для передачи визуальных параметров в веб-клиент.

**Черновые основные цвета:** `primary: #4757BE`, `background: #F8F9FD`, `surface: #FFFFFF`, `accent: #9AF0DD`, `text: #20243A`. Это рабочая палитра, не утверждённый брендбук. В экранах авторизации используется **Inter**; окончательный шрифт нужно закрепить единообразно для всего проекта.

### \#18899 — Вайрфреймы

Подготовлены схемы для следующих экранов в **desktop- и mobile-вариантах**:

|Экран|Основные элементы|
|-|-|
|Каталог мероприятий|Поиск, фильтры, список карточек, переход к подробностям|
|Страница мероприятия|Название, описание, дата/место, организатор, действие **«Пойду»**|
|Вход|Email, пароль, переход к регистрации, восстановление доступа|
|Регистрация|Имя, email, пароль, повтор пароля, согласие с условиями|
|Каталог секций|Поиск/фильтры, карточки секций, переход к подробностям|
|Страница секции|Информация о секции, расписание/описание, действие записи|

Для списков и страниц предусмотрены примеры **загрузки, отсутствия данных и ошибки**. Для форм входа и регистрации вместо «пустого списка» используются начальное состояние незаполненной формы и ошибки валидации.
