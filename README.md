# Tusumba — Sprint 1: заявки, профиль, модерация

**Задача:** #19063 «Макеты: заявки, личный кабинет, кабинет модератора»  
**Статус:** подготовленные макеты для согласования; не являются реализованными интерфейсами или утверждённым контрактом API.  
**Платформа:** веб (React/Vite/TypeScript), адаптивность Desktop/Mobile. Android/Compose упомянут в задаче, но отсутствует в описанной архитектуре Tusumba — требуется уточнение у руководителя.

## Содержимое

|Экран|Основные элементы|Действия|
|-|-|-|
|Новая заявка|Название, категория, дата/время, место, описание, организатор, email, обложка (макет), черновик|Сохранить / отправить на проверку|
|Мои заявки|Список, ID, дата, статусы: черновик, на проверке, одобрена, отклонена|Создать / открыть / редактировать черновик|
|Профиль|Данные пользователя, контактные поля, ссылки на личные разделы|Редактировать|
|Мои записи|Предстоящие мероприятия и секции; статусы участия|Подробнее / отменить (демо)|
|Кабинет модератора — очередь|Список ожидающих заявок, поиск, сортировка, статусы|Открыть заявку|
|Кабинет модератора — карточка|Описание и атрибуты события, организатор, история, решение|Одобрить / отклонить с причиной|

Для каждого вида подготовлены адаптивные формы для **Desktop 1280px** и **Mobile 390px** (12 базовых экранов), а также **loading**, **empty/initial**, **error** (18 дополнительных состояний). Содержимое редактируется нативными слоями Figma; HTML — отдельный интерактивный прототип.

## Открыть в браузере

Файл `Tusumba\_Design\_System\_v1.4\_Sprint1\_19063.html` запускается локально двойным кликом и не требует сервера. В разделе `#19063` доступны переключатели экрана, состояния и ширины. Формы и решения модератора выполняются только внутри браузерной демонстрации, **данные не отправляются на сервер**. Старые разделы дизайн-системы и вайрфреймов #18899 сохранены.
